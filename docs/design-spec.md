## 1. 배경과 목표

2026-08-11~12 검증 결과:
- KOSPI 대형주 모멘텀(24조합) — ❌ NO-GO: 전 조합이 KOSPI200 B&H(+214%)에 열세

- RSI(2) 평균회귀 — 유일 생존: 대형주 top20, 923건, 비용 0.30% 후 +66bp/건, wr 66%, 0.45%에서도 양수, 파라미터 패밀리 robust. 단 자본노출 ~13%로 연 3~4% 수준

**결론 구조 = 코어-새틀라이트**: 백테 승자(지수 B&H)를 코어로 깔고, 검증된 유일 엣지(RSI2)를 새틀라이트로 올린다. 봇의 역할은 "지수를 이기는 것"이 아니라 "코어 + 얇은 엣지의 자동 운용"이다.

### 목표
- KIS(한국투자증권) 계좌 하나를 통째로 자동 운용: 코어 70% + 새틀라이트 30%
- 모의투자 → 실계좌 100~300만원 파일럿

### 비목표 (명시적 제외)
- 지수 초과 알파 추구 (백테상 불가 판정)
- 숏, 레버리지, 분봉/장중 전략, 미국주식 (2단계 보류)
- 새틀라이트 동적 배분 (미검증 — 백테 통과 시 토글로 추가)
- 대시보드 (파일럿 제외, 포트 5030 예약만)

## 2. 전략 규칙 (백테 검증분 무변형)

### 새틀라이트 (RSI2 딥바잉)
- 유니버스: 연초 KOSPI 보통주(코드 끝자리 0) 시총 top20, 연 1회 갱신 (marcap 기준)
- 진입: `Close > SMA200 && RSI(2) < 10` (RSI는 Wilder EWM, alpha=1/2)
- 청산: `Close > SMA5`
- 슬롯: 최대 4개, 슬롯당 새틀자본의 25%. 신호 > 빈 슬롯이면 RSI 낮은 순 우선
  - ⚠️ 백테와의 편차: 백테는 종목당 고정 1/20 배분(슬롯 제한 없음)이었고, "슬롯 4개 + RSI 낮은 순 선택"은 백테에 없던 규칙. 거래당 기대값(+66bp)은 배분 무관하나 포트폴리오 결과는 달라질 수 있음 → 모의투자 단계에서 4슬롯 변형의 신호 선택이 백테 트레이드의 부분집합인지 확인, 필요 시 4슬롯 변형 백테 추가
- 손절 없음 (Connors 구조 — SL 비대칭이 평균회귀 기대값을 죽인다는 6월 %B 검증과 일관)

### 실행 타이밍 (백테=라이브 정합성의 핵심)
- 15:19 KST: 당일 가격으로 신호 계산 (백테는 종가 기준)
- 15:20:30 동시호가에 시장가 주문 제출, 컷오프 15:25 (`scheduler.TRADE_CUTOFF`) — 이후엔 장외 시장가 발사 위험이라 스킵, 다음날 재평가
- 오차원은 "15:19 가격 vs 확정 종가" 차이뿐 — 신호 경계 근처에서만 발생, 모의투자 단계에서 실측

### 코어 (KODEX 200, 069500)
- 목표 비중 70%, ±5%p 밴드 이탈 시에만 리밸런싱, 월 1회 체크 (매월 첫 거래일)
- 배당/분배금은 현금으로 적립 → 다음 리밸런싱에 흡수

### 현금
- 새틀 슬롯이 비는 만큼 현금 보유 (백테상 새틀 평균 노출 ~13% → 평시 현금 20~25%)

## 3. 아키텍처

```
Stock_trader/
├── signal/
│   ├── indicators.py   # RSI(2), SMA — 순수함수, 백테·라이브 공용
│   └── strategy.py     # (가격데이터, 보유상태) → 주문의도 리스트. 순수함수
├── portfolio/
│   └── allocator.py    # 코어 밴드 체크 + 새틀 슬롯 배분 → 주문의도. 순수함수
├── data/
│   ├── market.py       # KIS 일봉 조회(당일 포함), KRX 휴장일 — 파일럿 미구현
│   │                   #   (컷오프 가드가 휴장일 주문을 무해한 거부/스킵으로 한정)
│   └── universe.py     # 연 1회 유니버스 갱신 스크립트 (marcap)
├── broker/
│   └── kis.py          # KIS 공식 Open API REST 직접 호출 (공식 예제 리포 패턴).
│                       #   모의↔실전 = KIS_MODE 환경변수 (도메인·TR·키 전환)
│                       #   일봉은 FID_ORG_ADJ_PRC=0(수정주가), 주문응답엔 체결가 없음→현재가 폴백 필수
├── executor.py         # 주문의도 → 주문 → 체결확인. 체결가 누락 시 현재가 폴백
├── events/log.py       # jsonl append: signal/order/fill/rebalance/error/daily_summary
├── notify/telegram.py  # 진입/청산/에러/일일요약
├── main.py             # 상주: 5분 heartbeat 로그 + 15:19 신호/15:20:30 동시호가 제출
│                       #   (컷오프 15:25) + 월초 리밸런싱
├── backtest/           # bt_rsi2.py 이식 — signal/ 모듈을 임포트해서 실행 (동형성)
│                       #   — 파일럿 미구현 (골든 테스트로 동등성만 검증, §6 참조)
└── tests/
```

### 설계 원칙
- **v3/v4 코드 0줄 재사용, 패턴만 계승**: 이벤트소싱 jsonl(v4), 원자쓰기, 텔레그램, watchdog 편입
- **순수함수 코어**: signal/portfolio는 I/O 없는 순수함수 → TDD·백테 공유 가능
- **백테=라이브 동형성**: 백테 하니스가 라이브와 같은 `signal/` 모듈을 임포트. 골든 테스트로 3종목(005930/000660/005380) 158건 트레이드 재현 검증 (동일 로직이므로 유니버스 20종목 전체는 이 로직 공유로 담보 — §6 참조)
- **상태의 진실은 KIS 잔고**: 시작/일일작업 전 `positions.json`과 대사, 불일치 시 KIS 기준 adopt + 텔레그램 경고 (v3 sync 교훈)

### 실행 모델
- 상주 프로세스 (docker), 내장 스케줄: 5분 heartbeat 로그(기존 watchdog의 "5분 로그 신선도" 판정 호환), 평일 15:19 신호 계산/15:20:30 동시호가 시장가 제출 (컷오프 15:25 — 이후엔 스킵, 다음날 재평가)
- KIS 웹소켓은 체결통보 수신용만 (일봉 전략에 실시간 시세 불필요) — **파일럿 미구현** (컷오프 가드가 휴장일/장외 주문을 무해한 거부/스킵으로 한정하므로 체결통보 실시간성이 필수가 아님). REST 폴링 폴백 병행

## 4. 에러 처리

원칙: **"하루 놓쳐도 안 죽는다"** — 일봉 전략의 여유를 명문화. 크래시 루프보다 보수적 정지.

| 상황 | 처리 |
|------|------|
| KIS API 장애/토큰 만료 | 재시도 3회 → 오늘 스킵 + 텔레그램 |
| 주문 미체결 (동시호가 이월 등) | 장 종료 후 확인 → 취소 → 다음날 재평가 |
| 체결 응답 가격 누락 | FILLED 확인 시 현재가 폴백 기록 (v3 2a60e5d/70287a1 교훈) |
| 거래정지·상하한가로 매도 불가 | 자동 처리 금지, 텔레그램 에스컬레이션 |
| positions.json ↔ KIS 잔고 불일치 | KIS 기준 adopt + 경고 |
| 휴장일 | KRX 캘린더로 스킵 — **파일럿 미구현** (컷오프 가드[15:25]가 휴장일 주문을 무해한 거부/스킵으로 한정하므로 별도 캘린더 없이도 안전) |

## 5. 단계 게이트 (시뮬≠실거래 — 김치봇 교훈)

1. **KIS 모의투자 4주+**: 매일 신호를 백테 로직으로 재현 100% 일치 + 체결가 vs 종가 오차 실측
   체크리스트:
   - (a) 15:19 시점 `daily_closes`의 마지막 bar가 당일인지 확인 (전일자면 신호가 하루 지연됨)
   - (b) 조회되는 chart가 수정주가(액면분할/배당 조정)인지 확인 (원주가면 SMA200/RSI2 왜곡) — 설계 반영됨: 공식 파라미터 `FID_ORG_ADJ_PRC=0`(수정주가) 명시 사용, 모의에서 분할 이력 종목으로 재확인만
   - (c) 로테이션 데이(SELL과 BUY가 같은 날 겹칠 때) SELL 체결대금이 같은 날 BUY 주문가능금액으로 인정되는지 (동시호가 체결 확정 전 가용금액 처리 방식은 증권사 정책 확인 필요)
   - (d) 장외 시간/휴장일에 주문을 넣었을 때 거부 동작 확인 (컷오프 가드가 우회되는 경로가 없는지)
2. **실계좌 100만**: 통과 조건 = 4주 무크래시 + 신호일치 + 평균 체결오차 <10bp
3. **300만 증액**: 실계좌 3개월 평가 (백테 기대치 거래당 +50~70bp, wr ~65%와 비교)

- E2E: 모의투자 계좌로 주문→체결→대사 사이클
- pre-commit pytest 게이트: `set -eo pipefail` (v4 6/28 교훈)

## 8. 리스크와 한계 (정직하게)

- 새틀 엣지는 얇다: 새틀 30% 기준 계좌 기여 연 ~1%p 수준. 이 봇의 가치는 초과수익보다 **자동 운용 + 주식봇 인프라 확보**
- RSI2는 2018·2020 약세장에서 손실 (5구간 중 2개) — 코어도 같이 빠지는 구간. 계좌 MDD는 지수 MDD(-36%)에 수렴한다고 봐야 함
- 백테는 배당 미포함(전략·지수 동일 조건), 1/N 단리 근사 — 절대수치보다 방향으로 해석
- 2025~26 폭등장이 백테 후반을 캐리 — 향후 성과는 코어 비중만큼 시장을 따라감
